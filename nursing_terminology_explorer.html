    계층 탐색

    분류(ICD/KCD)는 한 개념이 한 자리에만, 용어(SNOMED CT)는 여러 부모(is-a)를 가질 수 있습니다.

    KCD-9 ICD-10 장 → 블록 → 범주

    상호배타적 단일 계층: 각 개념은 하나의 경로만 가집니다. 개념을 누르면 오른쪽 SNOMED CT 계층과 비교됩니다.

    SNOMED CT is-a 관계

    내장 데이터 범위(직접 부모 + 최상위 계층) 내 시각화입니다. 금색 선은 다중 부모를 뜻합니다.

    상호운용성 시뮬레이터

    두 병원이 같은 환자 상태를 서로 다른 로컬 용어로 기록했습니다. 각 로컬 용어를 알맞은 표준코드(SNOMED CT)에 매핑해 데이터를 통합하세요.

    💡 마우스: 용어를 코드 카드로 드래그 · 터치/키보드: 용어를 탭(Enter)한 뒤 코드 카드를 탭(Enter) · 매핑된 용어를 다시 누르면 해제됩니다.
